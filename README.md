## 🗓️ Scheduler App (Beginner Full-Stack Project)

A simple full-stack Scheduler application built as a learning project to understand how frontend and backend systems work together.

⚠️ Note:
This project is intended for beginners and learning purposes only.
It is feature-complete and not actively maintained.

## 📌 About the Project

- The Scheduler app allows users to:
- Register and log in securely
- Create and manage scheduled events/tasks
- View events using a calendar-style interface

⚠️ Note: 
The goal of this project was not to build a production-ready system, but to gain hands-on experience with full-stack development concepts.


## Features

- User registration and login with secure JWT authentication
- Password hashing with bcrypt for security
- Interactive calendar to create, edit, and view tasks/events
- Responsive design using Material UI and Emotion styling
- Form validation using Formik and Yup
- REST API backend built with Express and MongoDB
- CORS enabled for cross-origin requests

## Technology Stack

### Frontend

- React
- React Router DOM
- Material UI (MUI) and Emotion for styling
- React Calendar
- Formik and Yup for forms and validation
- Axios for API calls

### Backend

- Node.js and Express.js
- MongoDB and Mongoose
- JSON Web Tokens (JWT) for authentication
- bcrypt for password hashing
- dotenv for environment variables
- CORS middleware

### Prerequisites

- Node.js installed on your machine (v16 or above recommended)
- MongoDB instance (local or cloud, e.g., MongoDB Atlas)

## 🚀 Getting Started (Optional)

If you want to run the project locally:
- Clone the repository
- Install dependencies in both frontend and backend folders
- Create a .env file using the example below
- Start backend and frontend separately

Example .env: 
- MONGO_URI=your_mongodb_connection_string
- JWT_SECRET=your_secret_key
- PORT=5000
